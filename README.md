# Supply-Chain-Management-Analysis
**About:** A Supply Chain Management project analyzes how a business manages its products, inventory, customer orders, shipping, and deliveries.
**Objectives:** Order Analysis ie Calculate Total Orders and identify order trends by year,region and shipping mode.                                                                  Inventory Analysis ie Track stock on hand, identify low-stock products, and calculate reorder requirements.                                                           Delievery Performance ie Calculate Lead Time, On Time Delivery percentage and Shipping Performance.                                                                   Sales and Revenue Analysis ie Analyze Total Sales Revenue, Regional Performance, and Top-performing cities or Products.                                               Demand and Reordering Analysis ie Compare the forecast demand with the actual demand and identify when the inventory replenishment is required.
**Tools used**: Excel, PowerBI, Tableau, Mysql
**Database:**: 2 Fact Tables ie Fact_Orders and Fact_Inventory Table.                                                                                                                4 Dimension Tables ie Dim_Product,Dim_Customers,Dim_Suppliers,Dim_Warehouse
